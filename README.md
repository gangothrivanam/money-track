### Track Today. Plan Tomorrow. Make Your Money Last.

MoneyTrack is a personal finance management web application designed to help users understand where their money goes and, more importantly, determine **how much they can safely spend each day until their next income**.

Unlike a basic expense tracker, MoneyTrack continuously recalculates the user's available money and daily spending limit based on income, commitments, emergency savings, expenses, and remaining days.

---

## 🚀 Why MoneyTrack?

Many people know how much money they earn, but they don't know:

- Where their money is going
- How much they can safely spend today
- Whether they are spending too quickly
- How much money they will have before their next salary
- How to manage unexpected expenses

MoneyTrack solves this by turning financial information into simple, actionable daily guidance.

---

## ✨ Key Features

### 🔐 User Authentication
- User registration
- Login and logout
- Personal user experience
- Local browser-based data storage for the current version

### 💵 Income Management
- Add monthly salary/income
- Set next salary date
- Track available income

### 📌 Fixed Commitments
Users can record recurring financial commitments such as:

- Rent
- EMIs
- Bills
- Education fees
- Family expenses
- Subscriptions
- Other fixed expenses

### 🛡️ Emergency Reserve

Set aside an emergency amount before calculating the money available for daily spending.
